How to crop a GIF

  1. 01

    Choose an animated GIF

    Select Choose a GIF or drag a GIF from your device into the editor. Wait for the preview, then watch it through one loop so you can see how far the subject moves. If the preview is still, check whether the original moves and whether the editor shows more than one frame next to the file name. A GIF can contain a single frame, so choose the animated original if you expected motion.

  2. 02

    Set the crop size and position

    Drag the crop frame over the area you want to keep, then pull its handles or enter the width and height in pixels. Both values must fit within the original dimensions shown above the preview, so a 320 × 180 GIF can have a square crop up to 180 × 180. Choose Square to link the dimensions for a 1:1 crop. For fine positioning with a keyboard, focus the crop frame and press an arrow key to move it 1 pixel, or hold Shift to move it 10 pixels.

  3. 03

    Preview the full loop and download

    Select Crop GIF and watch a full loop in the result preview before downloading. If a hand, caption, or other important detail gets cut off midway, move or enlarge the selection on the original and crop again. Use Reset to full image to start over with the full frame. If the result moves in the browser but looks still where you shared it, open the downloaded GIF in a browser to check playback and confirm the destination supports animated GIFs.

Frequently asked questions

Does my GIF leave my device?

No. This tool processes GIFs in your browser. Your image is not sent to a server.

Will the animation keep playing?

Accepted results retain the frame count, frame delays, and loop information. If we cannot keep the colors or animation information, the crop is declined.

What if a GIF cannot be cropped?

Check the editor message first. If the file is too large, see the supported file limits below. If the file opens but a crop fails, try moving the frame or choosing a smaller crop. Some GIFs use frame structures the tool cannot preserve for a particular crop.

Does cropping resize the GIF?

Cropping removes the pixels outside the selection. To make the entire animation smaller while keeping the full scene, you need to resize it.

Can I crop a GIF that already has a transparent background?

Transparency inside the selected area stays part of a successful freeform or square crop. For a circular result with transparent corners, use the circle GIF cropper.

Will a crop make the GIF file smaller?

Check the result's file size after exporting. It depends on how the remaining pixels change from frame to frame and how the animation is encoded.

Can I move the frame with the keyboard?

Focus the crop frame and press an arrow key to move it by one pixel. Hold Shift with an arrow key to move it by ten pixels.

Which browsers should I use?

Tested on desktop Chrome, Edge, and Firefox, and on Android Chrome. Use an up-to-date browser with JavaScript and WebAssembly enabled.

Supported files and browsers

GIF files only. Current limits: 20 MiB per file, 4,194,304 canvas pixels, 500 frames, and 60,000,000 total frame pixels. All limits apply together. Processing stops after 60 seconds. These are protective limits, not a guarantee that every GIF within them will work on every device.
