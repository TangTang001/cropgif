Gifsicle source and build materials

The wrapper's embedded WASM is byte-identical to the core in @wasm-codecs/gifsicle 1.0.0, whose build scripts use Gifsicle 1.92. Download the Gifsicle source and browser build materials (ZIP), including the C source, build scripts, wrapper source and original notices. Source notes and version references and checksums are also available. The historical toolchain has not been rebuilt here.
