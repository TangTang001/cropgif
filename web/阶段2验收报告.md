# GIF Crop 阶段 2 验收报告

日期：2026-11-02。状态：**阶段 2 完成**。范围依据第一版开发计划“裁剪交互”；沿用已确认的白灰底、蓝色按钮及选区原型。

## 实现与约定

- 首次进入显示选择文件入口；导入后播放原动画，显示文件名、原图尺寸、帧数和大小，默认选区精确覆盖全图，自由比例。
- 选区状态为原图整数像素。支持移动、八个边角手柄，边界最小 1×1；宽高输入与拖动使用同一状态，不增加 X/Y 或中心坐标输入。
- 修改宽高优先保留左上角；扩大后越界则向图内移动。空值、负数、小数和超限值保留为编辑草稿，提示错误并禁止 Crop；另一个字段的输入不会悄悄覆盖非法草稿。Escape 恢复最后有效选区。
- Square 取当前框内居中的最大正方形，奇数差值按最近整数定位；输入任一尺寸同步两边。角缩放固定对角，边缩放固定对边并以另一轴中心扩展。切回 Freeform 保留当前框；Reset 恢复全图自由比例。
- 图片自适应编辑区，ResizeObserver 重新测量；Pointer Events 每次按当前显示边界换算原图坐标。滚动、CSS 缩放和浏览器页面缩放均不把 CSS 尺寸传给引擎。
- 方向键移动 1px，Shift + 方向键移动 10px；手柄可聚焦并用方向键缩放。输入有可见标签、错误描述和焦点提示；触摸扩大手柄命中区域。
- 调整选区或输入立即清空旧预览、撤销下载 URL；只有点击 Crop 才创建处理任务。继续使用阶段 1 的生产 Worker 和 H 路由。
