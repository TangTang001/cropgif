# GIF Crop 阶段 3 验收报告

日期：2026-11-02。状态：阶段 3 完成。

## 交付

- 页面显式管理 empty、loading、ready、processing、success、error 状态。加载和处理中禁用文件、选区及重复提交；非法尺寸单独阻止提交。
- 下载名称保留经过清理、限长的原文件名，并附实际裁剪尺寸；过滤路径、控制字符和 Windows 保留名称。示例：CON.gif 的 2×2 结果为 gif-CON-crop-2x2.gif。
- 成功后预览动画及尺寸/大小。改变选区、替换文件和失败会撤销旧结果 URL 和下载属性；下载只绑定当前成功任务。
- 损坏、选区不兼容、超限及超时使用不同提示；超时保留原图和选区，恢复操作。
- 页面离开时终止任务、撤销 URL；任务序号防止已离开页面的异步结果回写。浏览器缓存恢复页面时重建原图 URL。

## 验证

13 项 Node 定向检查和生产构建通过。Chrome 155.0.8059.39、Edge 156.0.4314.58 在生产静态预览中分别通过：

1. 六种任务状态均实际出现；两次真实下载分别与各自当前 Worker 的输出字节一致，且不同裁剪输出不同。
2. Windows 保留文件名清理后的实际下载名称正确。
3. 真实 A 兜底结果可实际下载，下载与当前 Worker 输出一致。
4. 三个已知 511 色复杂选区明确拒绝，无下载入口；每次之后正常文件均可成功。
5. 真实损坏 LZW 输入拒绝，不能借 A 绕过；之后同页正常处理成功。
6. 受控测试仅在浏览器测试中将 60 秒缩短为 350ms，并注入持续运行任务及子 Worker。超时后子 Worker 心跳停止，全部 Worker 终止；页面控件恢复、原图可见，随后真实生产任务成功。
7. 两侧各创建/终止 Worker 26/26；最终仅保留原图及当前结果两个页面 URL，没有累计旧结果。此项是生命周期验证，不是进程内存峰值测量。

页面错误、远程 HTTP 请求均为 0。测试通过真实 UI 入口选择文件、调整选区、Crop 和下载；Worker/URL 观测及受控超时只由测试脚本注入，正式包没有测试开关。处理算法、H 路由及依赖版本未变。
