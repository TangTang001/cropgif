GIF Crop Lab

Privacy

Updated November 2, 2026.

Your GIF stays on your device

GIF Crop Lab reads and processes the file you select in your browser. The crop tool does not upload your GIF, filename, crop settings, or generated image to a server. Previews and downloads use temporary browser URLs.

Website requests

Your browser requests the website's HTML, scripts, styles, and icons from its hosting provider. Normal website requests can include your IP address, browser information, and the requested URL. Browser-local image processing does not prevent the hosting provider from handling this connection information.

Cookies and analytics

The current application does not set cookies, store your files in local storage, or include advertising or analytics scripts. If we introduce analytics, we will update this notice to describe the service and data collected.

Closing the page and saving files

Replacing a file or closing the page releases the application's temporary references. Your browser and operating system manage memory and caching; this is not a guarantee of secure deletion. GIFs you download remain wherever you save them.

Support

You can find the project and report problems on GitHub. GitHub is an external service with its own privacy practices. Keep private images on your device. Start with your browser version and the error message; share a sample GIF only if you choose to do so and have permission to share it.
