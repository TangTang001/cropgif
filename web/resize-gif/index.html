Tips for resizing GIFs

Fit an exact width and height

Use Dimensions when you know the size you need. Drag the handles for a visual adjustment or enter the pixel values directly. Keep the aspect ratio locked to preserve the original shape.

Scale both sides together

Use Percentage to resize relative to the original. At 50%, a 320 × 180 GIF becomes 160 × 90. If you enlarge a small GIF, check the preview for blocky edges before downloading.

Frequently asked questions

Will my resized GIF stay animated?

Successful exports keep the original frame count, frame delays, and loop setting.

How do I resize a GIF without stretching it?

Keep Lock aspect ratio on when entering a width or height, or use Percentage to scale both dimensions together. The editor rounds to whole pixels.

Will resizing make my GIF file smaller?

Smaller dimensions often reduce file size. The final size also depends on what changes between frames and how the animation is encoded. Check the file size shown next to the download button.

Should I resize or crop my GIF?

Resize to scale the full image. Use the GIF cropper to remove edges or keep only part of the frame.

Does my GIF leave my device?

Your browser reads and resizes the GIF locally. Your file stays on your device.

Supported files and sizes

Choose a GIF up to 20 MiB and 500 frames. Both the original and the resized GIF must fit within 4,194,304 pixels per canvas and 60,000,000 pixels across all frames. If the output exceeds these limits, choose a smaller size.
