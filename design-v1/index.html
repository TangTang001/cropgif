Frequently asked questions

Does my GIF leave my device?

No. This preview processes GIFs in your browser. Your image is not sent to a server.

Will the animation keep playing?

Accepted results retain the frame count, frame delays, and loop information. If we cannot keep the colors or animation information, the crop is declined.

What if a GIF cannot be cropped?

Some GIFs use frame structures this version cannot preserve for a particular crop. Try a different crop area or another file.

Which browsers should I use?

This desktop preview is intended for Chrome and Edge. Mobile devices and other browser engines have not been verified.
